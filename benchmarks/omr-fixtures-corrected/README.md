# Corrected CC0 OMR benchmark fixtures

These fixtures use the same original CC0 reference MusicXML as
`benchmarks/omr-fixtures`, with two engraving defects fixed so the printed
PDF contains the notation the reference describes:

1. The benchmark music font lacked a quarter-rest glyph. The original
   generator silently drew every quarter rest with the eighth-rest glyph
   (`0xE4E6`). The corrected font adds SMuFL `0xE4E5` (quarter rest) and the
   generator maps duration 12 to it.
2. The original generator drew a flag only for durations <= 6, so dotted
   eighth notes (duration 9) and tuplet eighth notes (duration 4) had no
   flag/beam and looked like quarters. The corrected generator draws one
   flag for durations 4, 6 and 9, and two for duration 3.

The original `benchmarks/omr-fixtures` corpus is preserved unchanged. These
corrected PDFs are separate reference-backed validation material: the truth
MusicXML is unchanged, and no reference notation is read during recognition.

Generated by `scripts/generate-omr-corrected.py` with the font built by
`scripts/build-omr-corrected-font.py` (both CC0 research tooling).
