## Sound licensing status (was a live safety issue)

Before this release the live bundle loaded clean-electric-guitar samples from
`https://nbrosowsky.github.io/tonejs-instruments/samples/guitar-electric/` — a
wrapper redistribution whose originating owner (Karoryfer) could not be
verified. Verified live after the release:

- that host appears **0 times** in the live bundle
- samples load from the same-origin mirror `/audio/guitar-electric/`
- a live browser run recorded **77 audio requests, all to corranzo.com, 0 cross-origin**
- CC0-1.0 / Emilyguitar / Karoryfer-attribution / Salamander credits are present in the live bundle

## Audio Vision compatibility with Score Following

The chord-duration fix (a `<chord/>` note now reuses its parent onset's
duration) removes the invalid MusicXML that previously made Audio Vision
arrangements read as overfull:

- **solo-guitar**: `timingValidation: valid`, 0 overfull, 0 impossible cross-measure WFY requirements, TAB mirrors preserved
- **solo-piano**: 1 measure still notates more content than 4/4 holds, so it is **flagged** `timingValidation: invalid` (never hidden); WFY asks per written measure and 0 impossible requirements are produced. Live engraving renders 17 noteheads / 4 measures and WFY paints the required notes correctly.

The tempo correction control is now **always available** (was gated on
"ambiguous or varying"), pre-filled with the estimate, and persisted per
recording by fingerprint — all verified live (generated at 117 BPM, rebuilt
at 150 BPM).

### Deliberately NOT shipped (documented follow-up)

`9648f75220` (Audio Vision, newer than the requested `a42068a716`) fixes the
remaining piano overfull-measure case but also **removes the TAB staff from
generated guitar arrangements** (single G clef instead of notation + TAB).
That is a product decision for the Audio Vision owner, not something to slip
into this release. The current release keeps TAB and handles the piano flag
honestly. Integration is a single merge away (`git merge 9648f75220` onto
`release-sound-and-av`) but should be reviewed with the Audio Vision owner.
